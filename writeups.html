Bedside
Medical-imaging box where the same pickle-deserialization bug shows up twice. CVE-2025-64512 lets a crafted PDF's CMap reference trigger unpickling in pdfminer.six for a foothold inside a Docker container; a Vite dev server's path traversal then leaks a host SSH key. Root falls to a sudo-run MONAI/PyTorch trainer that loads the newest checkpoint via torch.load(weights_only=False) from a directory writable by the container account.

Paperwork
Print-queue-themed box built on bespoke Python services. A custom RFC 1179 line-printer daemon injects the job name straight into a shell command for a foothold; a path-traversal bug in a hand-rolled JetDirect/PJL emulator then plants an SSH key for a second user. Root falls when a "security" watchdog leaks a live root file descriptor over a Unix socket whose contents double as root's own login password.

MakeSense
WordPress box built on client-side trust. A theme ships its own AES key, so a forged "voice message" plants a stored XSS an admin bot renders — creating an admin and a plugin-upload webshell. A reused wp-config password gives SSH; root falls to a root-owned OCR service that saves recognised text to a web-served .php file, so Tesseract writes the webshell.
